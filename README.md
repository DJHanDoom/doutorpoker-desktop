# Doutor Poker Desktop

Instalador do [Doutor Poker](https://doutorpoker.web.app) para Windows. Este repositório guarda só os instaladores, não o código do programa.

**[Baixar a versão mais recente](https://github.com/DJHanDoom/doutorpoker-desktop/releases/latest/download/DoutorPoker-Setup.exe)**

## ⚠️ Antes de usar

Regras de salas como o iPoker proíbem software que aconselha ou automatiza o jogo, e a punição pode ser fechar a conta e confiscar o saldo. Confirme com o suporte da sua sala o que é permitido. O uso é por sua conta e risco; o modo estrito do programa reduz o risco, mas não o elimina.

## O que vem no instalador

- **Doutor Poker:** o app fora do navegador, com as mãos em um banco de dados neste computador. Depois do primeiro login, abre sem internet.
- **TableKit:** hotkeys, botões e o HUD sobre as mesas.
- **Companion:** traz as mãos das pastas de histórico do seu cliente de poker.

## Ao instalar

- O instalador ainda não tem assinatura digital, então o navegador e o Windows podem alertar. No navegador, escolha manter o arquivo. No Windows, clique em **Mais informações → Executar mesmo assim**.
- Instale sem mesa aberta: o instalador fecha o programa para atualizar.
- O primeiro login precisa de internet e abre no seu navegador.
